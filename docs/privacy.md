# 隐私说明

适用版本：FTA-Senior-Android v0.1.0。

FTA 在设备本地运行，不提供账号、广告、统计或数据上传功能，不申请 Android 网络权限。

## 使用的数据

- **应用包名、名称和系统状态**：用于识别当前应用、展示白名单、判断进程及保护对象。
- **无障碍窗口信息**：只使用窗口类型、焦点及根节点的应用包名，不遍历页面文字，不读取输入内容，不截图。
- **本地设置**：按钮外观、开关、横竖屏位置、保护规则和白名单。
- **操作记录**：执行时间、结果、相关包名和失败／跳过原因，最多保留 50 条。

设置和操作记录保存在应用私有存储中。可在“记录”页面清空操作记录；清除应用数据或卸载会移除本地设置与记录。应用关闭 Android 自动备份。

## 权限

Shizuku 授权用于查询系统状态和强制停止应用；无障碍服务用于识别应用及显示按钮；查询全部应用权限用于白名单与保护判断；震动权限用于触感反馈。不会使用上述权限采集或上传屏幕内容。

## 主动导出

“复制诊断信息”会在用户操作后将版本、连接状态及错误信息写入系统剪贴板。Windows 日志脚本会通过用户连接的 ADB 将设备信息、包版本和系统日志保存到电脑上的 `shizuku-log.txt`，不会自动上传。

系统日志可能包含其他应用包名或设备信息。向 GitHub Issue 等公开渠道提交前，请检查并删除无关或敏感内容。
